# TrustLend Level 5 User Feedback Form - Setup Guide

## Google Form Configuration

### Form Title
**TrustLend User Testing & Feedback Form**

### Form Description
```
Help us improve TrustLend by sharing your experience!
Your feedback is crucial in making this platform better and more secure.
This should take 5-10 minutes.
```

---

## Required Fields (Mandatory)

### 1. Full Name
- **Type**: Short Answer
- **Question**: What is your full name?
- **Required**: YES

### 2. Wallet Address
- **Type**: Short Answer
- **Question**: What is your Stellar wallet address? (For identifying your account)
- **Required**: YES
- **Help Text**: (Optional) Please enter your public wallet address starting with 'G'

### 3. Email Address
- **Type**: Email
- **Question**: What is your email address?
- **Required**: YES

### 4. User Type
- **Type**: Multiple Choice
- **Question**: What type of user are you on TrustLend?
- **Options**:
  - Borrower (Seeking loans)
  - Lender (Investing in pools)
  - Both
- **Required**: YES

---

## Feedback Questions (At Least 3 Required)

### Question 1: Feature Gaps
- **Type**: Long Answer / Paragraph
- **Question**: Is there any feature you think TrustLend is lacking? What would make the platform more useful for you?
- **Required**: YES
- **Help Text**: For example: Two-factor authentication, mobile app, automated repayment, etc.

### Question 2: Bugs/Issues
- **Type**: Long Answer / Paragraph
- **Question**: Did you find any bugs, errors, or issues while using the app? Please describe them.
- **Required**: YES
- **Help Text**: Include steps to reproduce if possible

### Question 3: Problem Solving
- **Type**: Dropdown / Multiple Choice
- **Question**: Do you think TrustLend is able to solve the micro-lending issue it's targeting?
- **Options**:
  - Strongly Disagree
  - Disagree
  - Neutral
  - Agree
  - Strongly Agree
- **Required**: YES

### Question 4: Overall Experience (Optional - Bonus)
- **Type**: Linear Scale (1-5)
- **Question**: How would you rate your overall experience with TrustLend?
- **Scale**: 1 (Poor) to 5 (Excellent)
- **Required**: NO

### Question 5: Net Promoter Score (Optional - Bonus)
- **Type**: Linear Scale (0-10)
- **Question**: How likely are you to recommend TrustLend to a friend or colleague?
- **Scale**: 0 (Not at all likely) to 10 (Extremely likely)
- **Required**: NO

### Question 6: Additional Suggestions (Optional - Bonus)
- **Type**: Long Answer / Paragraph
- **Question**: Any additional comments, suggestions, or feedback?
- **Required**: NO

---

## Form Settings to Enable

- ✅ **Shuffle question order**: OFF (keep in order)
- ✅ **Collect email addresses**: Enable if not using email field
- ✅ **Show progress bar**: ON
- ✅ **Make this a quiz**: OFF
- ✅ **Limit to 1 response**: OFF (allow multiple if needed for testing)
- ✅ **Show link to edit responses**: OFF

## Response Collection & Analysis

### Where to find responses:
1. Go to your Google Form
2. Click "Responses" tab
3. View in Sheets for easier data management
4. Download as CSV or Excel

### Automated email notifications:
- Enable in settings to get notified for each response
- Good for tracking when users submit feedback
